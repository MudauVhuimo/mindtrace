# MindTrace (frontend)

The complete web app that powers https://mind-trace.studio.

See the root `Readme.md` for full instructions, deployment, etc.

Quick local:
```bash
npm install
# GEMINI_API_KEY in .env.local
npm run dev
```

Prod:
```bash
npm run build
NODE_ENV=production npm start
```

All the good stuff (formatting engine, share links, navigation, history, dark flat UI) is here.
